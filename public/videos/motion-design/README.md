# Motion Design Videos Directory

Place your motion design video files (`.mp4`, `.webm`, `.mov`, `.m4v`) in this directory.

### Recommended formats:
- **Format**: MP4 (H.264 / AAC) or WebM (VP9 / Opus)
- **Aspect Ratios**: 16:9 (1920x1080) for desktop showcases, 9:16 (1080x1920) for mobile/reels, or 4:3 / 1:1 for UI micro-interactions.
- **Optimization**: For fast web loading, compress videos using Handbrake, FFmpeg, or Adobe Media Encoder (recommended bitrate: 2-5 Mbps).

### Default Video Filenames Configured in Portfolio:
- `reel-showcase.mp4` / `reel-showcase.webm` (Main Showreel)
- `product-interaction.mp4` (UI & Micro-interactions)
- `brand-motion.mp4` (Brand Animations & 3D)
- `fintech-app-flow.mp4` (Mobile App Motion)
- `dashboard-analytics.mp4` (SaaS Dashboard Interactions)
- `onboarding-experience.mp4` (Seamless Onboarding Motion)
